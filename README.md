# Elanster Technologies — Landing Page

Single-page, fully responsive landing site for Elanster Technologies.
Static HTML/CSS/JS — no build step, no dependencies. Open `index.html` or serve the folder.

## Structure

```
index.html          # all sections, logo recreated as inline SVG
css/styles.css      # design tokens, layout, responsive rules
js/main.js          # nav, marquee, services carousel, reveals, counters, FAQ
assets/fonts/       # Sharp Grotesk (width 20) — Light/Book/Medium/SemiBold/Bold
assets/img/         # brand logo PNGs (favicon + fallback)
```
